# Tic Tac Toe

A simple, interactive Tic Tac Toe web game built with vanilla HTML, CSS, and JavaScript. Features local 2-player support, real-time win/draw detection, and a built-in light/dark mode switch.

## Features

- **2-Player Gameplay:** Take turns placing **O** and **X** on a standard 3x3 grid.
- **Win & Draw Logic:** Automatically detects all 8 possible win patterns or a tie game after 9 moves.
- **Theme Switcher:** Seamlessly toggle between dark and light color themes.
- **Game Controls:** Includes "Reset Game" and "New Game" buttons to quickly clear the board and start fresh.
- **Responsive Sizing:** Board layout built using CSS `vmin` units to fit comfortably on both desktop and mobile screens.
